8 formatos de tiempo · YouTube (yout-ube) · HTML5 · MP4 externos · Estáticos locales

📌 Formatos Absolutos (inmediatos)

1️⃣ Rango Exacto [MM:SS-MM:SS]

#op=[00:30-02:00]&ed=[02:00-03:30]
→ OP: 30s→120s | ED: 120s→210s

2️⃣ Rango Implícito [MM:SS]

#d=120&op=[01:30]
→ OP: 90s→210s (90+120 con d=120)

3️⃣ Duración Explícita MM:SS+Ns

#op=01:00+45s
→ OP: 60s→105s (60+45 explícito)

4️⃣ Punto Fijo MM:SS

#op=00:30&ed=03:20
→ OP: 30s (punto) | ED: 200s (punto)

📐 Formatos Relativos (inicio y final)

5️⃣ Relativo al Inicio +N

#op=+30
→ OP: 0s→30s (primeros 30s)

6️⃣ Relativo al Final -N

#ed=-90
→ ED: (duración-90)→duración (últimos 90s)

7️⃣ Hasta el Final [MM:SS-]

#ed=[02:30-]
→ ED: 150s→duración (desde 2:30 al final)

8️⃣ Desde el Inicio [-MM:SS]

#op=[-01:30]
→ OP: 0s→90s (desde inicio a 1:30)

📹 Videos HTML5 Nativos (.mp4 externos)

🌊 MP4 Externo — Rango Exacto HTML5

data-video-params="op=[00:10-00:30]&ed=[00:35-00:46]"
→ Fuente: vjs.zencdn.net/v/oceans.mp4 (46s de duración)

🌊 MP4 Externo — Relativo al Final HTML5

data-video-params="op=+15&ed=-10"
→ OP: 0s→15s | ED: (duración-10)→duración

🌊 MP4 Externo — Rango Implícito HTML5

data-video-params="d=20&op=[00:05]"
→ OP: 5s→25s (5+d=20)

🌊 MP4 Externo — Open-ended HTML5

data-video-params="ed=[00:30-]"
→ ED: 30s→duración (desde 0:30 al final)

🐘 MP4 Externo (Big Buck Bunny) HTML5

data-video-params="op=[00:30-01:00]&ed=[09:00-]"
→ Fuente: Google Cloud Storage (10 min de duración)

🐘 MP4 Externo — Primeros Segundos HTML5

data-video-params="op=+30&ed=-60"
→ OP: 0s→30s | ED: (duración-60)→duración

📖 Guía de Formatos (Referencia Rápida)

# Sintaxis Tipo Ejemplo Resultado
1 [MM:SS-MM:SS] Absoluto op=[01:30-03:00] 90s → 180s
2 [MM:SS] Absoluto op=[01:30] 90s → 180s (con d=90)
3 MM:SS+Ns Absoluto op=01:30+45s 90s → 135s
4 MM:SS Absoluto op=01:30 90s (punto fijo)
5 +N Rel. inicio op=+30 0s → 30s
6 -N Rel. final ed=-90 (dur-90) → dur
7 [MM:SS-] Rel. final ed=[22:00-] 1320s → dur
8 [-MM:SS] Rel. inicio op=[-01:30] 0s → 90s

🚀 Características del DLC

  • 8 formatos de tiempo: 4 absolutos + 2 relativos al inicio + 2 relativos al final
  • Transformación automática YouTube: youtube.com → yout-ube.com y youtu.be → yout-ube.com/watch?v=
  • Soporte HTML5 nativo: videos con .mp4 locales o externos
  • Auto-skip: prefijo ! para salto automático sin botones
  • Resolución de duración diferida: formatos -N y [MM:SS-] se resuelven al detectar duración
  • Fallback de duración: si no se detecta duración en 5s, usa d= como estimación
  • Plataformas: YouTube, ok.ru, Vimeo, VK, HTML5
  • Botones flotantes con diseño moderno, animaciones suaves y auto-ocultamiento
  • Detección automática de nuevos videos via MutationObserver
  • API pública para control programático

🔧 Uso Programático

// Agregar un video manualmente window.videoSkipButtons.addVideo(elementoVideo, 'op=[01:30]&ed=-90'); // Transformar URL de YouTube programáticamente const url = iframeMatrixViewer.transformYoutubeUrl('https://youtu.be/abc123'); // → "https://www.yout-ube.com/watch?v=abc123" // Actualizar configuración de un video window.videoSkipButtons.updateVideoConfig('video-id', { op: { start: 60, end: 180 }, ed: { start: 1320, end: 1410 } }); // Destruir el DLC window.videoSkipButtons.destroy();
